This is a simple planning tool based on assumptions, not a quote. It does not check availability, inventory, postcodes, parking, vehicle suitability, VAT treatment or insurance. Specialist items need a survey.

Why so many questions?

Bedroom count is not enough

Two homes with the same number of bedrooms can have very different volumes, access and journey times. A real quotation should be based on belongings and conditions, not just a property label.

No data collection

Private by design

The estimator only uses the selections on this page. It does not ask for contact details or transmit information to a server.
